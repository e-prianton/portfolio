# PORTFOLIO PERSONAL

Bienvenidos a este proyecto personal que será mi carta de presentación via página web.

# Tecnología:

Las primeras fases del proyecto se compondrán de HTML, CSS y JavaScript puros, creando una web estática, aunque poco a poco se le añadirán elementos para que adquiera algo de dinamismo.

Se publicará con la herramienta GitHub Pages para comodidad inicial sin tener que depender de otros servicios.

# ¿Para qué sirve?

A nivel personal, sirve para desarrollar mis conocimientos tanto en desarrollo web como en integración de proyectos, ya que la idea es ir actualizando y mejorando la web. Sin usar plantillas de base ni CMS, consultando ideas a través de internet y con la ayuda de la IA pero sabiendo qué es lo que quiero y cómo, ya que la idea es aprender en el proceso, no solo tener una página funcional y ya. 

A nivel profesional, servirá como una presentación sobre mi carrera profesional y los aprendizajes que estoy llevando a cabo para mejorar mis salidas laborales.

Al principio, será una web tosca sin demasiado formato, a medida que avance el proyecto se irán añadiendo mejoras de formato, modo oscuro/claro, timelines, etc. haciéndola más profesional.

## Versión V1.0

El proyecto contendrá los archivos mínimos y la información básica para tener una página web lista y funcional en poco tiempo. Será una web tosca sin demasiado formato.

Para ello la web se compondrá de:
- Header, que contendrá mi nombre y mi rol como titulo y subtitulo, añadiendo la progresión a automatización
- Menú de navegación dentro del header con los apartados:
    - Home
    - Sobre mi
    - Proyectos
    - Habilidades
    - Herramientas
    - Contacto
- Body, que contendrá la información correspondiente a cada apartado de la opción del menú seleccionado.
- Footer, que contendrá los derechos y la versión de la web.

Se usará una hoja de estilos general para toda la web. 
Se usará un html para cada sección.
Se usará un JS para crear la constante del header y el footer ya que siempre seran estáticos e iguales en todas las opciones del menú.
